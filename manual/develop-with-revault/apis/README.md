# APIs

The reVault APIs let applications create and manage Vaults and Lockboxes without invoking the CLI. Bindings provide the same core concepts in the conventions of each language.

Start with the [reVault API](revault-api.md) overview, then choose a language guide in this section for installation, native runtime selection, resource handling, and examples. Each guide links to the package's generated class or method documentation for exact signatures.
