Natural-pressure profile

The probe refuses to begin unless baseline VmLck is zero. It tries 64 capacities 8,192 + i*4,096, i=0..63 (maximum 266,240), across two passes, keeping one SecureVec live at a time. Each request uses a deterministic nonzero byte based on pass/index; exact length and complete scoped byte equality are checked. VmLck and VmRSS are recorded before, while live, and after drop; VmLck above the unchanged limit is fatal. Public API capacity is not exposed, so capacity is labeled source-inferred.

The first estimated cumulative crossing is index 60: request 253,952 bytes, projected new backing 258,048 bytes, prior cumulative 8,359,936 bytes. These figures are estimates only; actual outcome/resource samples are recorded. The old run accepts only the exact typed Error::WeakAllocationDisabled as expected refusal; any other error fails. The new run must complete exactly 128 allocations. Each profile run is capped at 30 seconds. No retry is allowed after either run.
