The prior default/native gate still failed on compressed protected writes. A
paired stage diagnostic on that baseline used ten ABBA/BAAB groups, six samples
per child and a discarded warmup, for encrypted-signed compressed 8 MiB pattern
writes. All 240 writes independently reopened and verified bytes. Native frame
preparation itself was +27.691% [20.112%,35.612%], while commit was -17.648%
[-24.205%,-10.509%]. This ruled out per-frame flushes as the complete explanation.
Stage counters overlap and default flush work is deferred into commit; stage
percentages must not be added or used as a whole-write regression gate.

Raw diagnostic lines and their summary are retained as stage-baseline.txt and
stage-baseline-summary.csv. Raw prefix: pair,position,reader; reader main is
current default, branch native. Following columns are the benchmark stderr
write-profile fields. Summary excludes sample 0, expands each named stage into
a synthetic write row with that stage's microseconds as total_us and other timing
fields zero, then uses protection_gate summarize. Those rows measure stages,
not standalone operations. Both layouts used identical dependency fingerprints
and requested numeric compression settings.

Implementation: FileImportPipeline::prepare uses Cow::Borrowed for exactly one
input frame, so encoding reads the caller's already-borrowed bytes directly.
It avoids constructing, copying and wiping a temporary concatenation buffer.
Multi-input packed frames still concatenate into an owned buffer. Parallel jobs
retain their transferred owned buffers, wiping them after encoding. Empty input
batches remain valid. Prepared stored bytes still use ZeroizingBytes, and original
caller bytes remain untouched. Slice metadata, codec choice, integrity and format
bytes are unchanged. No transaction flush or preparation protocol was altered.
The same shared pipeline change applies to default and native layouts; performance
results below compare native before/after, not native versus default.

Benchmark: pattern/random broad matrices each contain 320 measured rows, five
ABBA/BAAB groups, three child samples with the first discarded, 8 MiB data, all
four protection modes, raw/compressed, default padding, synthetic content keys.
Focused matrix: encrypted-signed/compressed/pattern, fifteen paired groups, six
samples per child with the first discarded, 300 measured rows.

Results: all 16 broad central estimates improve, by 1.8-11.4%. Many five-group
confidence intervals cross zero; those cases do not individually prove a gain.
The prespecified focused case improves 4.538%, with a 95% interval of
[2.836%,5.917%] lower write time. Pooled medians are 25.075 ms before and
23.923 ms after. Retain the copy elimination based on this confirmed target
improvement, unchanged output and passing correctness checks. No small-many,
other-size, cold-I/O or default-layout performance claim is made here.
All 940 measured rows plus warmups independently verified persisted bytes.
