rerun separately with more samples. The same exact before/after executables were
checked against their recorded SHA256 values; no implementation changes were made.

Protocol for each case:
  REVAULT_GATE_CHILD_SAMPLES=6 taskset -c 2 AFTER compare-write BEFORE AFTER ROOT
  8388608 random 25 CASE
CASE was encrypted/false/write and then plain/true/write. Groups alternate
ABBA/BAAB; each child drops one warmup and retains five measured samples. Each
case therefore has 500 measured rows, 250 per variant, across 25 paired groups.
No implementation builds or other tests were run concurrently by this agent.
All writes are independently reopened and compared byte-for-byte outside the
write timer. Archive sizes match between variants. Comparator progress messages
are excluded from CSV; no measured rows were discarded.

Both upper confidence bounds are below the +5% threshold for these two specific
before/after cases. The suspected increases in the earlier mixed run were not
reproduced. Neither interval excludes zero, so these runs do not establish a
statistically clear speedup. Keep the earlier mixed data as part of the record.
