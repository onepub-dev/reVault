Release zip_read benchmark, native-block-layout enabled. Binary hashes are
before the formatting-only pre-commit hook. Feature remains unreleased/opt-in.

The native-broad-read-current CSV is the BEFORE baseline (336 rows), despite
its historical filename. Three runs, five samples per row, plain mode,
pattern/random corpora, both compression settings and read profiles. Small:
512 x 4096 bytes, Interactive/BulkImport creation. Large: 4 x 1 MiB and
4 x 8 MiB, Interactive creation. Access: stream, random (Read handles),
whole (get_file), plus range for large files. Fresh archive handles, warm OS
caches. Every returned byte is checked. ZIP deflate ranges decode the prefix;
they do not validate the whole entry CRC. This is not a cold-storage gate.

This exposed repeated full compressed-frame decoding for separate handles of
packed files. Native compressed handles now enter the existing bounded,
verified decoded-frame cache on first read, retain only their file slice,
and check live storage identity/extent/revision/failure state on window hits.
Raw partial reads retain their bounded block reader; no eager raw-frame read.
The shared cache honors existing budgets and disabled-cache configuration.
No wire format, public API, default feature or cache budget changes.

The handle-cache-reads CSV contains 96 rows: three interleaved before/after
runs, five samples, plain mode, small case, both creation profiles, corpora,
compression settings and read profiles, ACCESS=random. Each phase verifies
480 MiB of returned bytes across independent reopened archive handles.
The compressed flag denotes the requested policy: incompressible corpus
falls back to raw frames, so those rows do NOT exercise the new compressed path.

Compressible packed handles improve about 209-211x, but still take 1.21x ZIP.
Interactive compressible handles improve 1.86x, remaining 1.22-1.27x ZIP.
Raw fallback and raw handles remain roughly 2.3-13.6x ZIP; they need metadata/
index reuse without expanding bounded raw range reads. Large-file baseline
also remains well short of parity (roughly 4.4-6.6x ZIP median whole reads).
These measurements do not establish broad parity, write lifecycle completion,
cold-storage performance, signed/encrypted speedup, or release readiness.

The external-source regression reads a neighboring compressed file through a
new public Read handle, checks every returned byte, and asserts zero additional
source reads. Existing all-mode tests cover raw bounds, seeks, retained-window
truncation/overwrite rejection, cancellation and sticky terminal failures.
