Public-path native-layout experiment, 2026-09-13
===============================================
The non-default native-block-layout Cargo feature enables the common writer,
TOC decoder/encoder, cached page ownership, native readers, scanner and recovery
in normal library builds. It selects native frames independently of encryption
and signing, including public streaming imports, survivor rewrites and compaction.
Historical mode-zero writes retain their historical writer. Without the feature,
the existing production output policy is unchanged. No format-version increment.

Public integration tests assert that real writes and compaction emit native
version-3 pages, then reopen, compare bytes, seek across a block boundary and
inspect recovery in all sixteen policy combinations. Existing creation, padding,
locking and public API lifecycle tests also exercise the feature-enabled build.

Integration found and fixed a key-boundary mismatch: public content keys may have
non-32-byte lengths. The native page adapter uses the existing domain-separated
page-key derivation for those lengths, retaining existing 32-byte native frame
keys exactly. The lower-level frame primitive still requires a 32-byte key.
Encrypted CLI writes and file-locking integration tests reproduce this boundary.

Recovery can infer a header candidate after restoring slot magics in a private
copy, preserving all original checksums and authentication tags. It never repairs
source storage or treats magic/checksum validity as owner authorization. Signed
snapshots still pass normal publication/commit/content authentication. Extra
header damage, truncation and a repaired-outer-page invalid owner signature remain
rejected. This supports the existing dual-header-damage public recovery test;
missing signed TOC data still fails closed when no snapshot can be verified.

ZIP parity is NOT achieved. Native raw streaming takes 2.53-2.66x ZIP and raw
whole-file random order 4.05-4.25x. Compressed streaming is 1.63-1.64x and compressed
random order 2.10-2.13x. Range results are 8.99-9.43x raw (about 1 ms total) and
1.13x compressed. These observations prioritize reducing per-call native index
and buffer work, not weakening validation. This run is not a paired main-branch
load or write comparison and provides no approval to accept a >5% regression.
