get_file directly returns the validated decoder buffer for one chunk covering the
entire file. Pending file bytes retain their precedence. Sparse, empty-without-
chunks, non-covering and multiple-chunk files keep the existing extraction path.
This avoids cloning/sorting a one-element chunk list and copying the complete
output through an additional Vec writer. A mismatched decoded length fails with
the temporary decoded buffer wiped.

For the bounded small-frame source snapshot, exact read already detects a short
source. Remove only the duplicate pre-read current_len query. Before any decoded
bytes escape, the existing final check still validates source identity, physical
extent (including padding), and the write revision captured before reading.
The snapshot/body validators and external source's own failure checks are retained.
The all-mode small external-source test now additionally truncates the native
physical page by one byte and requires refusal.

Profiling rationale: an intermediate direct-return-only variant was recorded with
perf record -e cycles:u -F 499 --call-graph dwarf, running zip_read with CASE=small,
MODE=plain, ACCESS=whole, SAMPLES=100, CREATE_PROFILE=Interactive, CORPUS=pattern,
PROFILE=Interactive, COMPRESSION=false (REVAULT_ZIP_READ_ environment prefix).
744 samples: SHA-256 compression accounted for about 27% self overhead and
archive_lock::current_len about 18% inclusive overhead. This profile includes
fixture creation, ZIP, open and byte checking, not just get_file. It guided the
source-check reduction; it does not justify weakening hashes or authentication.

Final measurements: issue310-native-direct-get-paired.csv, 96 rows. The same
interleaved three-run/five-sample whole-file protocol as the preceding cache and
small-snapshot notes, 512 files x 4096 bytes, plain mode, two corpora, creation
profiles, compression settings and read profiles. Fresh handles; warm OS caches.
Each phase byte-verifies 122880 returned files (480 MiB) per implementation.
The CSV contains only measurements after the successful final release build.
