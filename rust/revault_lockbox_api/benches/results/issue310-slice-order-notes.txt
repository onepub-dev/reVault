CompressionFrameManifest::slice_for and cached_frame_bounds now compare frame
offset, length and file offset before path equality. The cached variant also
checks expected total length before the path. This avoids string comparisons for
unrelated packed slices. All previous equality checks remain, iteration order is
unchanged, and slice_for still returns the first exact match. There is no sorting
assumption, new index, extra retained memory, format or public API change.
Source validation, hashing, signatures, encryption and cache policies are unchanged.
The shared lookup change applies to both layouts; timings here are native only.

Protocol matches the previous many-file comparison: eight alternating-order
before/after runs, nine samples per row, 512 x 4096-byte files, plain mode,
Interactive/BulkImport creation, both read profiles, both corpora and requested
compression settings, public Read handles (ACCESS=random), PASSES=1,2. Each
sample opens a fresh archive; passes share that archive handle. 512 rows total.
Large controls: three alternating-order runs, five samples, four 8 MiB files,
Interactive creation, both corpora/read profiles/compression settings,
ACCESS=random, PASSES=1; 48 rows. Every returned byte is checked on every pass.
CPU 2, warm OS caches, no agent builds/tests during timing. Unrelated host work
was active. Compression requested on incompressible input falls back to raw.

CSV prefix is phase,create_profile,passes,run followed by standard zip_read
columns. Summary uses median lockbox_ms and lockbox_over_zip per phase/group;
even medians average the two middle values. Speedup is before/after. These are
descriptive medians, not per-cell confidence intervals.

Targeted results: all eight BulkImport first-pass groups improve, 1.004-1.085x.
Packed compressible pattern reads improve 1.085x/1.026x on the first pass and
1.156x/1.149x for two passes (Interactive/ReadMostly respectively). Their first-
pass Lockbox/ZIP ratios fall to 1.021/1.068, approaching but not meeting a 10%
lead. Packed raw or incompressible reads remain about 1.86-2.11x ZIP on first
passes. Two repeated raw/random packed groups are slightly slower (0.977-0.990x).

Separate small-file controls span 0.954-1.080x, and large controls 0.972-1.124x;
those mixed movements do not justify an across-the-board improvement claim.
Retain the low-complexity predicate ordering for the consistent targeted packed
first-read results and stronger repeated compressed gains. The raw packed gap
and the issue's broader ZIP parity goal remain unresolved.
