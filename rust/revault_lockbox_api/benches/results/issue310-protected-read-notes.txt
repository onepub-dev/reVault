minimum/maximum paired change. These ranges are observations, not confidence
intervals. Three run medians do not establish a confidence-bounded release gate.
Ordinary ZIP has different security behavior, so protected cases are interpreted
as native-before versus native-after comparisons, not security-equivalent ZIP
parity. The plaintext cases still fail the overall ZIP parity objective.

The standalone Rust summary tool in benches/tools/summarize_read_matrix.rs
requires all 64 cases x three metrics and exactly runs 1/2/3 in both variants,
rejects duplicate runs and nonpositive/nonfinite timings, and pairs by run ID.
Compile with rustc and pass issue310-protected-read-matrix.csv. Its output was
verified byte-identical to the independently grouped exploratory summary.

This establishes broader performance evidence for retaining source-validation
reuse, including signed-open workloads. It does not validate damaged signed
