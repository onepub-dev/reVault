Issue #310: reject retained encoder state for large slice writes
Base fa0cb40; production unchanged from f4b1d91. Attached full candidate patch
is reverted, including candidate-only tests. Reproduce with git apply
--unidiff-zero. No production or dependency changes retained.

The preceding scoped-storage candidate rebuilt StaticEncoderWorkspace per frame.
This candidate keeps the initialized encoder and caller-backed scratch/output
alive across equal-sized frames within one synchronous large slice write. No TLS
or new unsafe code. Owning ZeroizingBytes locals outlive the encoder borrow and
wipe their full allocations on scope completion/error/unwind. Buffers never grow
or shrink while borrowed. Encoded output is copied to compact owned Vecs.
Short final frames, entropy-skipped data, unsupported scratch sizes and ordinary
non-numeric compression policies use the original path. Scratch bounded to32MiB.
This version eagerly initializes scratch and output to zero on allocation.
FileImportPipeline accepts an explicit encoder callback; ordinary callers retain
the original encoder, metadata construction and integrity calculation.

An initial differential test found valid but non-identical output at level18:
first mixed 131073-byte input encoded to65614 vs65615 bytes. Decoding was correct.
The final candidate preserves the ordinary path for levels18-22. Its differential
test then passes levels1-22 across repeated mixed/repetitive inputs, changed
frame sizes and empty input, comparing encoded bytes and independent round trips.
This is tested-case equivalence, not proof of identical output for every input.
No new file format or compression algorithm is introduced.

Possible remaining costs include initialization/wiping of the full codec arena
and compact-output copying. Their separate contributions were not measured.
StaticEncoderWorkspace also offers new_uninit with caller-provided MaybeUninit
storage; examining that API could avoid redundant initialization while retaining
full-capacity wiping, but that change has NOT been implemented or measured here.
This experiment does not justify weakening wiping or retaining a regression.
